파형

악기 — 색 영역별

색상환을 8개 영역으로 나눠 각각 다른 악기를 배정했습니다. 모든 악기가 3옥타브를 연주하며, 캔버스에서 위로 그릴수록 높은 음이 납니다. 항목을 누르면 그 악기의 색으로 그릴 수 있습니다.

    매핑 규칙

    Hue → 악기 · 음정
    색상환 8개 영역이 악기를, 같은 Hue가 스케일 안 음정을 정함
    세로 위치 → 옥타브
    위쪽이 높은 음 — 3개 밴드가 C3·C4·C5 옥타브를 담당
    Brightness → 음량
    gain = 0.05 + (brightness / 255) × 0.35
    Saturation → 음색 밝기
    배음 크기와 저역통과 컷오프를 함께 조절 — 채도 높음: 밝고 선명
    열 위치 → 시간
    start = currentTime + col × stepDuration (48열)
    가로로 이어진 같은 색
    한 음으로 합쳐 길게 — 지속형은 계속 끌고, 감쇠형은 주기적으로 다시 퉁김
