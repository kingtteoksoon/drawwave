# DrawWave

캔버스에 그린 그림 또는 업로드한 이미지의 색상 정보를 분석해 실시간으로 멜로디를 생성·재생하는 단일 페이지 웹 애플리케이션입니다.

빌드 단계, 서버, 외부 라이브러리 없이 **`index.html` 파일 하나**로 동작합니다.

## 실행

```bash
# 파일을 직접 열거나
open index.html

# 정적 서버로 서빙
npx serve .
```

## 구성

| 모듈 | 역할 |
|---|---|
| `DrawingEngine` | Pointer Events 처리, 브러시 5종 렌더링, 2차 베지어 스트로크 보간 |
| `ImageAnalyzer` | 캔버스를 48×24 오프스크린으로 축소해 열·밴드별 평균 색상(HSV) 추출 |
| `SoundMapper` | 색상 → 음높이/음량/음색 변환, 스케일 적용 |
| `AudioScheduler` | `AudioContext.currentTime` 기준 절대 시간 노트 예약 및 재생 제어 |
| `Visualizer` | 스캔 라인 및 `AnalyserNode` 파형 렌더링 |

## 드로잉

| 브러시 | 굵기 | 특수 반응 |
|---|---|---|
| 연필 | 1~4px (필압 비례) | 틸트 방향으로 그레인 질감·음영 변화 |
| 붓 | 2~22px (필압 비례) | 다중 반투명 스탬프로 부드러운 경계 |
| 마커 | 고정 폭 (챙 팁) | 틸트 각도로 닙 회전 → 서예체 굵기 변화 |
| 에어브러시 | 고정 반경 | 필압이 분사 밀도(입자 수)를 결정 |
| 잉크펜 | 0.5~4.5px (필압 비례) | 경계 선명, 불투명도 0.95 고정 |

필압·틸트는 `pointerType === "pen"`일 때만 실측값을 사용하고, 마우스·터치에서는 필압 0.5 / 틸트 0으로 폴백합니다. 현재 입력 상태는 캔버스 하단에 표시됩니다.

## 음악 변환 매핑

| 시각 요소 | 음악 요소 | 규칙 |
|---|---|---|
| Hue 0°~360° | **악기** | 색상환 8개 영역이 각각 고유한 합성 음색을 담당 |
| Hue 0°~360° | 음높이 | 선택한 스케일 3옥타브(C3~C6) 배열에 인덱스로 정규화 |
| Brightness 0~255 | Gain | `0.05 + (brightness / 255) × 0.35` |
| Saturation 0~100% | 음색 밝기 | 저역통과 컷오프 조절 — 높을수록 배음이 살아 밝고, 낮을수록 부드럽다 |
| 열 인덱스 0~47 | 재생 시각 | `startTime = audioCtx.currentTime + col × stepDuration` |

### 색 영역별 악기

Hue는 악기와 음높이를 함께 결정하므로(0°가 최저음, 360°가 최고음), 각 악기를 자기가 실제로 연주하게 될 음역에 맞춰 배치했습니다.

| Hue | 음역 | 악기 | 음색 |
|---|---|---|---|
| 345°~25° | 최저 | 일렉트릭 피아노 | 따뜻한 기음에 4배음이 어택에서만 스치는 로즈풍 |
| 25°~55° | 저 | 첼로 | 디튠 톱니를 낮게 필터링한 활 소리, 4.8Hz 비브라토 |
| 55°~85° | 저중 | 나일론 기타 | 삼각파 중심의 부드러운 플럭, 컷오프 하강 |
| 85°~150° | 중 | 나무 플루트 | 사인 기음 + 옅은 2·3배음, 5.0Hz 비브라토 |
| 150°~195° | 중 | 비브라폰 | 1·4·10배 부분음에 5.5Hz 트레몰로, 긴 감쇠 |
| 195°~245° | 중고 | 현악 패드 | 디튠 톱니에 사인으로 심을 채운 느린 바탕 |
| 245°~290° | 고 | 첼레스타 | 사인 + 3·5배음, 짧고 맑은 감쇠 |
| 290°~345° | 최고 | 뮤직박스 | 얇은 음에 긴 여운, 비조화 부분음은 아주 옅게 |

섞임을 위해 세 가지를 지켰습니다. 배음은 낮은 차수 위주로 쓰고 날것의 톱니와 비조화 부분음을 피했으며, 어택은 모두 완만하게 잡아 한 악기가 앞을 가리지 않게 했고, 지속형과 감쇠형을 번갈아 배치해 서로의 빈자리를 채우게 했습니다.

여기에 **공용 리버브**를 걸어 서로 다른 악기가 같은 공간에 있는 것처럼 묶었습니다. 임펄스 응답은 지수 감쇠 노이즈로 생성하므로(1.6초, 감쇠 지수 2.4) 외부 파일이 필요 없습니다. 마스터에서 dry 0.80 / wet 0.26으로 섞습니다.

모든 음색은 `OscillatorNode` / `GainNode` / `BiquadFilterNode` 조합으로 직접 합성합니다. 외부 샘플이나 라이브러리를 쓰지 않습니다.

부분음을 합치면 보이스 피크가 요청 gain을 초과해 색 영역마다 체감 음량이 달라집니다. `OfflineAudioContext`로 음높이 7종 × 채도 4종 전 조합의 최대 피크를 실측한 뒤 그 역수를 `norm` 계수로 적용해, 모든 악기가 Brightness가 지정한 음량에 맞춰 울리도록 맞췄습니다(0.918~1.299배 → 1.000~1.001배).

- 스케일: 펜타토닉(5음 × 3옥타브 = 15음) / 크로매틱(12음 × 3옥타브 = 36음)
- 템포: 열당 0.15~0.6초
- 열마다 세로 3개 밴드를 분석하므로 최대 3화음까지 동시에 울립니다. 밴드마다 색이 다르면 서로 다른 악기가 동시에 울립니다.
- 필압·틸트는 드로잉 입력 단계에서만 쓰이며 사운드 매핑에는 반영하지 않습니다.

### 무음 판정

배경(칠하지 않은 영역, 흰색에 가까운 픽셀)은 발음하지 않습니다. 밴드는 평균 잉크 커버리지가 2% 이상이거나 밴드 내 최대 알파가 0.22 이상일 때 발음합니다. 축소 과정에서 1px 선의 커버리지가 크게 떨어지므로 두 조건을 병행해 얇은 선도 소리가 나도록 했습니다.

## 소리가 안 들릴 때

재생 패널 하단의 **테스트 음(440Hz, 1초)** 버튼으로 앱 문제와 기기·브라우저 문제를 구분할 수 있습니다.

- 파형이 움직이는데 소리가 없다 → 브라우저 탭 음소거, 시스템 볼륨, 출력 장치 문제입니다. iPhone은 측면 무음 스위치가 켜져 있으면 들리지 않습니다.
- `오디오 출력: 차단됨` 이 뜬다 → 브라우저가 자동 재생을 막은 상태입니다. 페이지를 한 번 클릭한 뒤 다시 재생하세요.
- 재생을 눌렀는데 진행률이 0%에서 멈춘다 → `AudioContext`가 열리지 않아 오디오 시계가 진행되지 않는 경우로, 1.2초 뒤 안내 메시지가 뜹니다.

Safari는 `suspended` 외에 `interrupted` 상태도 쓰고, iOS는 사용자 제스처 안에서 노드가 한 번 울려야 출력을 엽니다. 두 경우 모두 처리합니다.

## 조작

- **재생 / 정지**: 버튼 또는 `Space` 키. 재생 중에는 드로잉 입력이 비활성화됩니다.
- **이미지 업로드**: PNG / JPEG. 캔버스 비율에 맞춰 contain 배치되며 이후 동일한 도구로 편집할 수 있습니다.
- 업로드 이미지는 `FileReader`로 클라이언트 메모리 안에서만 처리되고 외부로 전송되지 않습니다.

## 검증 결과

Chromium(Playwright)에서 확인한 값입니다.

- `pointermove` 처리 시간: 전 브러시 p95 0.5ms 미만, 300회 입력 중 16ms 초과 0건
- `ImageAnalyzer.analyze()` 평균 0.24ms (48열 × 3밴드)
- 노트 스케줄링: 144노트 74.3ms(노드 1,109개). 예약이 리드타임을 넘기면 첫 열이 과거 시각에 잡혀 한꺼번에 터지므로, 리드타임을 노트 수에 비례(`0.12 + n × 0.0012`초, 최대 0.6초)해 약 4배 여유를 둠
- 전체 곡 오프라인 렌더링: 121노트 14.2초에서 피크 -1.4 dBFS, RMS -13.1 dBFS (클리핑 없음, 8종 전부 발음)
- 악기 8종 모두 단일 음 렌더링에서 발음 확인. 감쇠형(일렉트릭 피아노·나일론 기타·비브라폰·첼레스타·뮤직박스)은 0.4초 시점 진폭비 0.002로 감쇠, 지속형(첼로·나무 플루트·현악 패드)은 1.01~1.31로 유지
- 매핑식·스케일 구성·HSV 변환 단위 검증 통과
- `AnalyserNode`에 실제 오디오 신호 도달 확인(고채도 입력에서 sawtooth 파형 관측)
- 모든 컨트롤에 레이블 부여, 포커스 링 3px 표시, 재생 상태 `aria-live="polite"` 안내
- 390px 폭에서 가로 스크롤 없음

## 브라우저 요구사항

Pointer Events와 Web Audio API를 네이티브로 지원하는 최신 Chrome / Edge / Safari (데스크톱·모바일). 폴리필을 사용하지 않습니다.
